# /branch

Создать новую ветку от текущего HEAD.

**Аргумент:** имя ветки (обязательно). Если пользователь не передал — спроси имя.

## Шаги

1. `git status` — предупреди при незакоммиченных изменениях; по желанию пользователя продолжи или остановись.
2. `git checkout -b <имя-ветки>` (или эквивалент `git switch -c`).
3. `git branch --show-current` — подтверди, что переключение прошло.

## Заметки

- Имя ветки: латиница, `-`, `/`, цифры; без пробелов по соглашению команды.
