# /switch-branch

Переключиться на существующую ветку или создать tracking-ветку от `origin`.

**Аргумент:** имя ветки.

## Шаги

1. Если аргумент пуст — спроси имя и остановись до ответа.
2. Корень репо: `git rev-parse --show-toplevel`, `cd` туда.
3. `git fetch origin` (или основной remote из `git remote`).
4. Логика переключения:
   - если локальная ветка есть — `git checkout <branch>` и при необходимости `git pull --rebase` с upstream;
   - иначе если есть `origin/<branch>` — `git checkout -b <branch> origin/<branch>`;
   - иначе — сообщи, что ветка не найдена; предложи `git branch -a` или создать новую через `/branch`.
5. Проверь: `git branch --show-current` совпадает с запрошенной.

## Не делать

- Не меняй произвольные конфиги приложения при простом переключении ветки.
