# /work-item

Старт работы по **универсальному** тикету без привязки к Jira: ветка + шаблон плана.

**Аргументы:** свободная строка. Ожидаемый формат (гибкий):

- `PROJ-123 Краткий заголовок задачи`  
  или только `Краткий заголовок` — тогда сам предложи slug ветки после короткого уточнения.

## Шаги

1. `git status --porcelain` — при грязном дереве предупреди; не сбрасывай чужие изменения. Если пользователь не готов — стоп.
2. Определи `BASE` как в `/push` (`main` или `master`).
3. `git fetch origin` и `git checkout "$BASE"` + `git pull --rebase origin "$BASE"`.
4. Сформируй **slug ветки**: латиница, нижний регистр, `kebab-case`, префикс из ID тикета если был (например `proj-123-short-title`). Максимум ~50 символов.
5. Если ветка уже существует локально или на `origin` — спроси: переключиться на неё, удалить и пересоздать, или прерваться.
6. `git checkout -b <slug>`.
7. Создай файл плана `.cursor/plans/<slug>.md` с шаблоном:

```markdown
# <slug>: <заголовок>

## Исходные требования

(что пользователь передал)

## План

- [ ] Шаг 1
- [ ] Шаг 2

## Команды проверки

(заполнить из README пакета)

## Commit message (черновик)

<type>(<scope>): <кратко>
```

8. Сообщи пользователю имя ветки, путь к плану и предложи дальше заполнить план и реализовать.

## Не делать

- Не ходить по REST внутренних трекеров без URL/токенов.
- Не делай пустой коммит и не пушь без запроса.
