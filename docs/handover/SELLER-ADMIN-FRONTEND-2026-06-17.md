## 1. Что построено (отсутствующие страницы)

- **Admin «Товары» (UC-02)** — новая вкладка + страница: добавить товар (название, категория, код
  маркировки, сумма выплат), таблица с поиском/фильтром по категории, удаление по одному с
  подтверждением. Бэкенд SKU CRUD (был 501-заглушкой) реализован: `POST/GET/PATCH/DELETE /api/v1/skus`.
- **Seller «Мои заявки на выплату» (S5.5)** — новый экран `/seller/payouts` со статусами
  (Новая → В обработке → Выплачена). Бэкенд: новый `GET /api/v1/payout-requests/me`.

## 2. Что исправлено (несоответствия флоу)

**Выплаты / регистрация (S5/S2):**
- Реквизиты теперь вводятся **в форме заявки** (номер телефона для СБП), а не берутся из профиля (S5.3, Р-5-A).
- **Поле суммы редактируемое** — частичный вывод (S5.1); убран минимум 1000 ₽ и лишние методы (card/sbp_bank).
- Из **регистрации убраны реквизиты выплаты** (S2.2). Бэкенд: активация продавца теперь по `phone + outlet`
  (раньше требовала payout — иначе продавец не активировался). Проверено: pending→active без payout.

**Уведомления / поддержка:**
- Удалён **in-app центр уведомлений** (колокольчик в шапке + список) — уведомления только в Telegram (S7).
- Контакт поддержки исправлен на **@nester256** (был `vliq_support`).

**Чек / админ-проверка:**
- Экран чека продавца теперь **показывает фото загруженного чека** (S4); главный экран — счётчики
  **«N одобрено · M на проверке»**.
- Админ: **полноэкранный просмотр фото** (открывает реальный файл), **«Скопировать ФН/ФД/ФП»**,
  **soft-delete** обработанных чеков (Отклонён/Выплачен), убрана кнопка **«Доработка»** (out of scope).
- Фото чеков сделаны **просматриваемыми**: бэкенд отдаёт browser-URL (`to_viewable_url`,
  `S3_PUBLIC_ENDPOINT`), MinIO-бакет public-read. Проверено: `file_url` отдаёт `200 image/png`.

  маппит в «Отклонён»; полное удаление жеста из SwipeDeck отложено как риск/низкий приоритет.

  колонкой «выпл.» в «Топ продавцов».

  бэкенд-эндпоинт аналитики.
