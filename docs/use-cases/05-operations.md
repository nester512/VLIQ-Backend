# Действия без экранов

Редкие действия, для которых в приложении нет экранов. Их выполняет технический специалист по просьбе
владельца. Как именно — в документации для разработки.

## UC-OP1. Добавить или отключить администратора
- Владелец называет человека (его Telegram) и роль: администратор или super admin.
- Технический специалист вносит его в список администраторов; доступ появляется при следующем открытии
  приложения. Если этот человек был продавцом, он будет попадать только в приложение администратора.
- Отключённый администратор больше не может войти; уже открытое приложение работает до истечения входа —
  до 6 дней.
- Постоянное добавление «для всех будущих обновлений» затрагивает и прод — только с «да» владельца.

## UC-OP2. Восстановление доступа продавца при потере Telegram
Новый аккаунт Telegram — это новый пользователь: без процедуры он не видит старые чеки, баланс и выплаты.
Автоматического переноса нет — ни по имени, ни по телефону.

1. **Обращение.** Продавец пишет в поддержку с нового аккаунта (Профиль → «Помощь»): ФИО, телефон из анкеты,
   примерная дата регистрации, точка.
2. **Проверка личности.** Один номер телефона доказательством не считается.
3. **Решение** принимает super admin.
4. **Перенос** — с указанием основания (не короче 10 символов):
   - новый аккаунт входит как этот продавец: чеки, баланс и выплаты те же;
   - старый аккаунт отключается сразу — «Этот аккаунт Telegram отключён»;
   - уведомления идут на новый аккаунт;
   - в журнале действий — кто, когда и на каком основании.
5. **Система откажет, если:** у продавца есть заявка «новая» или «в обработке» (сначала выплатить или
   отклонить); новый аккаунт — администратор; новый аккаунт уже зарегистрирован как продавец (или это тот
   же аккаунт). Пустую анкету, созданную простым открытием приложения, система удаляет сама.

Порядок для поддержки и открытые вопросы — [../procedures/ACCOUNT-RECOVERY.md](../procedures/ACCOUNT-RECOVERY.md).

## UC-OP3. Источники проверки чеков
- Список источников видит любой админ — в «Пути чека».
- Включить, выключить или поменять порядок может только super admin; каждое изменение пишется в журнал.
- Подключить proverkacheka — нужна оплаченная подписка; ключ доступа вносит технический специалист,
  в чат и документы он не попадает.

## UC-OP4. Минимальная сумма выплаты
Настройка системы, сейчас 3 000 ₽ (решение В-11). Новое значение сразу видят продавцы. Меняется только с
согласия владельца.

## UC-OP5. Освобождение места: фото старых чеков
По решению владельца фото уже решённых старых чеков (одобренных и отклонённых) можно заменить маленькими
заглушками, чтобы освободить место. Сначала — отчёт без изменений.
