### Admin Use cases (представитель бреда влик)
- Как админ просматиривать список продавцов с помощью некоторого интрефейса 
- Чеки
	- Как админ просматиривать список чеков с помощью некоторого интрефейса
	- Удалять обработанные чеки (soft-delete)
	- По каждому чеку администратор видит
		- фото / файл чека;
		- пользователя;
		- дату загрузки;
		- распознанные данные;
		- найденные товары;
		- сумму бонуса;
		- риск дубля;
		- комментарий системы.
	- Действия:
		- Одобрить
		- Отклонить
		- Отправить на доработку
		- Изменить сумму бонуса
		- Заблокировать пользователя
		- Добавить комментарий
- Как админ могу получить аналитику с помощью некоторого интрефейса
	- п13
- Как админ могу получить уведомления о действиях **Продавцов**
	- п14
- Как админ мы можем создавать акции
	- Увеличение кол-ва баллов через Супер админа
	- иной функционал out of scope
- Как админ я могу взаимодействием чеки с помощью интерфейса
	- Как **Админ** просмотреть фото чека
	- Как **Админ** принять предоставленный **Продавцом**
	- Как **Админ** скопировать какой-то номер
	- Как **Админ** может отклонить предоставленный **Продавцом** чек
